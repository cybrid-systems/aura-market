# M4 — causal features

A feature quoter is `(lambda (fair inv drift imb) ...)`. `drift` is the
fair step already applied on this tick. `imb` is the sum of the previous
four inventory changes. The current fill is not in `imb`. The M0
two-argument quoter is unchanged. A probe quoter
`(bid-qty = 5 + drift, ask-qty = 5 + imb)` scores `32` on seed
`20261005`, which is not the wide score `18`.

`(2 2 2 0 0 0)` scores `50` on seed `20261005` and its panel minimum
is `-4`, so it is DROP. `(3 3 0 0 0 0)` has panel minimum `36` against
wide `18`, so it is KEEP. The race line carries `min=`.

特征在本拍成交之前算定。`imb` 不含本拍成交。M0 的两参报价仍然可用。
