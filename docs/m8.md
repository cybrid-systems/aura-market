# M8 — rolling window

The live book sums the last 12 ticks of `(delta pnl − delta penalty)`.
It does not call `mk:reset!`. `*tick*` only increases. Wide, with the
tick-8 bias bump, scores `-15` on ticks 1–12 and `1` on ticks 13–24.

A window swaps `mk:law` only when that score is strictly above the stored
base. The next window calls `hot-strategy:heal!` when it is not strictly
higher. A strictly better trial stays. `mk:shadow` takes the same body,
and later windows compare against that score.

The smoke arms fixture packs only. `six_keep` `(3 3 0 0 0 0)` swaps at
tick 36 and stays at tick 48, where the window score is `10`. `fat_side`
swaps at tick 60 and heals at tick 72, where the window score is `0`.
`(mk:law)` and `(mk:shadow)` are the kept pack again. The run ends at
tick 72.

`bash scripts/smoke_m8.sh` prints `MARKET_M8_OK`.
