# M5 — grid search

`mk:fitness` maps an integer pack to its panel minimum. It does not swap
and it does not write the main book. `(3 5 0)` scores `18`.

`std/swarm` kind `grid` is required and not modified. Floats are quantized
with `floor(x + 0.5)` and clamped before they reach the book: spread
`1..6`, size `1..8`, weights `-4..4`. Bias stays `0`. A point outside
the clamp is kept and clamped, not dropped.

The smoke grid is 3 dimensions, 3 bins, population 16. Bounds are spread
`1..5`, size `1..5`, and `w-drift` `-4..4`. That window includes
`(3 3 0 0 0 0)`, whose panel minimum is `36`. `MARKET_SWARM_EVALS`
defaults to 16 and is forwarded by `scripts/run_soft.sh`. Candidates past
the budget are not scored. A second run keeps the same winner.

KEEP only when that minimum is strictly above the shadow. A tie DROPs
and `hot-strategy:heal!`. An all-bad grid does the same, and heal does
not zero `*tick*`. This path does not call MiniMax.

Parallel search prints `panel=seq` and does not spawn inside fitness.
Asking for panel fibers while that flag is on prints `NESTED_SPAWN_FAIL`
and stays sequential. With the flag off, the panel is one fiber layer
(`joins=4/4`).

`bash scripts/smoke_m5.sh` prints `MARKET_M5_OK`.
